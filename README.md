# 🌌 Ascension of Ages — Modpack & Server Sync

Репозиторий для автоматической и быстрой синхронизации сборки **Ascension of Ages (NeoForge 1.21.1)** между хостом сервера и игроками.

---

## 📁 Структура репозитория

```
AscensionOfAges-Sync/
├── 🎮 client/             # Полная клиентская сборка (моды, конфиги, KubeJS, текстуры)
│   ├── mods/              # Все проверенные и оптимизированные клиентские моды
│   ├── config/            # Настроенные конфигурации модов
│   ├── kubejs/            # Скрипты прогресса и рецептов
│   ├── resourcepacks/     # Ресурспаки
│   └── defaultconfigs/
├── 🖥️ server/             # Серверные файлы и скрипты запуска
│   ├── mods/              # Серверные моды
│   ├── config/            # Конфигурации сервера
│   ├── user_jvm_args.txt  # Оптимизированные параметры памяти JVM (4G - 6G)
│   ├── run.bat            # Скрипт запуска с авто-мониторингом инцидентов
│   └── monitor_server.ps1 # Авто-детектор крашей и зависаний
├── ⚡ update_client.bat    # Батник для друзей: быстрое обновление сборки (Delta Sync)
├── 🚀 push_updates.bat    # Батник для хоста: отправка изменений на GitHub в 1 клик
├── .gitignore             # Защита от утечки конфиденциальных данных и логов
└── README.md
```

---

## 🔒 Безопасность и Конфиденциальность (100% защита)

В репозитории настроен строгий фильтр `.gitignore`. **Никакие конфиденциальные или личные данные не попадают в Git:**
* ❌ Миры и координаты (`world/`, `DIM*`, `region/`)
* ❌ Сохранения игроков, инвентари и могилы (`playerdata/`, `ftbteams/`, `tombstone/`)
* ❌ IP-адреса, порты и пароли (`server.properties`, `banned-ips.json`)
* ❌ Права администраторов и белые списки (`ops.json`, `whitelist.json`)
* ❌ Логи и дампы ошибок (`logs/`, `crash-reports/`, `incidents/`, `simplebackups/`)

## 👥 Инструкция для друзей (Как обновлять игру без скачивания 2 ГБ)

### 1. Первый запуск (один раз):
1. Склонируйте этот репозиторий в любую папку на компьютере:
   ```bash
   git clone https://github.com/rds0645010/AscensionOfAges-Sync.git
   ```
2. Запустите файл **`update_client.bat`**.
   * Скрипт сам найдет вашу папку `.minecraft` и скопирует все моды и настройки.

### 2. Последующие обновления (когда хост что-то изменил):
1. Просто запустите **`update_client.bat`**.
2. **Delta Sync** проверит только те файлы, которые изменились:
   * Если изменился 1 конфиг или 1 мод — скачается ровно **10 КБ - 5 МБ** за 2 секунды вместо повторного скачивания 2 ГБ!
   * Устаревшие или удаленные моды автоматически удалятся, предотвращая конфликты версий.

---

## 👑 Инструкция для хоста (Как отправлять обновления)

Когда вы изменили настройки, добавили/удалили мод или обновили скрипты:
1. Запустите файл **`push_updates.bat`** в папке репозитория.
2. Скрипт автоматически:
   * Заберет свежие файлы из вашей рабочей папки `.minecraft` и `AscensionServer`.
   * Закоммитит изменения с датой и временем.
   * Отправит обновление на GitHub (`git push`).
